# Tic-Tac-Toe Game

A console-based Tic-Tac-Toe game implemented in Java.

## Features

- Two-player turn-based gameplay
- Input validation
- Win and draw detection

## Prerequisites

- Java Development Kit (JDK) 8 or higher
- Standard console terminal

## Compilation

```bash
javac Main.java TicTacToeGame.java
java Main
```
